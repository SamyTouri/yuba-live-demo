# Yuba Live — démo

Démonstration d'un tableau de bord de suivi de campagne en temps réel pour **Yuba Group** (activation urbaine, Wallonie-Bruxelles).

**Voir la démo : https://samytouri.github.io/yuba-live-demo/**

## Le concept

Les équipes terrain (jobistes) envoient de simples **vocaux WhatsApp** tout au long de leur tournée :

> « Salut, ici Théo — j'ai transporté 2 personnes vers le centre de don, fait 3,8 km autour de Namur centre… »

Un agent IA transcrit, structure et consolide chaque message en quelques secondes. Les clients de Yuba suivent leurs campagnes **en direct** : flyers distribués, conversations engagées, personnes transportées, équipes sur le terrain.

Aucune appli à installer pour les équipes. **Un vocal suffit.**

## Cette démo

- 100 % statique (HTML/CSS/JS, zéro backend) — les données sont **fictives** et simulées en temps réel.
- 3 campagnes d'exemple inspirées de l'univers Yuba : Croix-Rouge (vélos-taxis don de sang), Visit Wallonia (screenbikes), Quick (ouverture Mons).
- L'architecture de la solution réelle est décrite dans [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
